This is a warioware style game with high school related minigames that was made in the Godot editor using the 2d scenes and Godot script.

To view this project, visit https://krupapramod.itch.io/2-kool-4-skl. Click the link to open and play, it is hosted on itch.io

Features include:
- an opening window with a start button and a quit button
- an intro slide that explains what the game is about and a preview of upcoming minigames
- an break inbetween each minigame, and between losses, with a timer
- a running count of lives as users progress
- three minigames: a platformer, a clicker, and a memory game
- a unique win and loss scene

  This was created with photos from Pinterest, and coded in Godot script and designed in the Godot editor. This was then hosted on itch.io which provided this playable link.

  This was designed with the aid of a guide provided by Hack Club's Stardance program.
